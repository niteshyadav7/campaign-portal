1to7 Media Portal - Professional Website Design Plan
====================================================

Goal
----
Make the entire portal feel professional, premium, calm, and trustworthy.
The UI should not look AI-generated, overly bold, overly dark, or randomly colorful.
It should feel like a polished SaaS operations product for brands, campaigns, creators, and approvals.


1. Overall Visual Direction
---------------------------
Use a clean day-mode SaaS design.

Design keywords:
- Calm
- Premium
- Organized
- Trustworthy
- Smooth
- Light
- Professional
- Operational

Avoid:
- Too much black
- Too many loud gradients
- Heavy font-black everywhere
- Oversized shadows
- Random colors on every component
- Marketing-style landing page sections inside the app
- Decorative elements that do not help hierarchy

Preferred look:
- Soft warm white backgrounds
- Mint, teal, sky, and small amber accents
- Clean cards with light borders
- Modern typography with medium weights
- Smooth but subtle animation
- Full-height layouts where appropriate


2. Typography System
--------------------
Primary font:
- Use a modern sans-serif stack.
- Recommended CSS stack:
  "Inter", "Aptos", "Segoe UI Variable", "Segoe UI", Arial, sans-serif

Display font:
- Use the same family or a slightly tighter display stack.
- Recommended CSS stack:
  "Inter Tight", "Aptos Display", "Segoe UI Variable Display", "Segoe UI", Arial, sans-serif

Why:
- Inter feels modern and product-focused.
- Aptos and Segoe UI are strong Windows fallbacks.
- This avoids needing external font downloads.

Font weight rules:
- Page hero headings: 600
- Page titles: 600
- Section titles: 600
- Card titles: 500 or 600
- Labels: 500
- Body text: 400
- Helper text: 400 or 500
- Buttons: 500 or 600
- Numbers/stat values: 600

Avoid:
- Do not use font-black globally.
- Do not use font-extrabold unless it is a rare emphasis.
- Do not use bold uppercase labels everywhere.

Recommended sizes:
- Login hero headline: 56px to 64px desktop, 36px mobile
- Page H1: 32px to 40px
- Page H2: 22px to 28px
- Card heading: 16px to 20px
- Body text: 14px to 16px
- Table text: 13px to 14px
- Labels: 13px to 14px
- Small meta text: 12px

Line height:
- Large headings: 1.02 to 1.12
- Section headings: 1.2
- Body copy: 1.55 to 1.7
- Table rows: 1.4

Letter spacing:
- Default should be 0.
- Use uppercase labels sparingly.
- If uppercase is used, keep tracking subtle: 0.04em to 0.08em.
- Avoid very wide tracking like 0.18em or 0.24em except tiny decorative badges.


3. Color Palette
----------------
Use a professional light palette with controlled accents.

Base colors:
- Page background: #FBFDF9
- Warm surface: #FFFDF8
- Main card: rgba(255, 255, 255, 0.72 to 0.92)
- Border: #DDF5EA or rgba(16, 185, 129, 0.18)
- Text strong: #1F2937
- Text normal: #334155
- Text muted: #64748B

Primary accent:
- Emerald: #059669
- Teal: #0D9488

Secondary accent:
- Sky: #0EA5E9
- Cyan: #06B6D4

Warm accent:
- Amber: #F59E0B
- Orange: #F97316

Danger:
- Red: #DC2626
- Danger background: #FEF2F2
- Danger border: #FECACA

Success:
- Emerald: #059669
- Success background: #ECFDF5
- Success border: #A7F3D0

Gradient rules:
- Use gradients only for important highlights.
- Headline gradients should use 2 colors only.
- Recommended headline gradient:
  from #0D9488 to #0EA5E9
- Button gradient:
  from #059669 via #0D9488 to #0EA5E9
- Avoid more than 3 colors in one gradient except decorative background art.
- Do not use black in gradients unless specifically requested.


4. Layout System
----------------
Use a consistent shell for the whole portal.

Spacing scale:
- Page padding desktop: 24px to 32px
- Page padding mobile: 16px
- Section gap: 24px to 32px
- Card padding: 18px to 24px
- Form field gap: 16px
- Toolbar gap: 12px to 16px

Content width:
- Login form max width: 500px to 560px
- Dashboard content max width: none for data-heavy pages
- Tables should use full available width

Grid:
- Dashboard cards: 3 or 4 columns desktop
- 2 columns tablet
- 1 column mobile

Avoid:
- Too much empty space between operational elements
- Nested cards inside cards
- Floating page sections that look like marketing blocks


5. Radius, Borders, and Shadows
-------------------------------
Border radius:
- General UI radius: 8px
- Inputs: 8px
- Buttons: 8px
- Cards: 8px
- Dialogs: 8px
- Circular stats or avatar-like cards may use 999px radius.

Border style:
- Use soft borders:
  rgba(15, 23, 42, 0.08)
  rgba(16, 185, 129, 0.16)
  rgba(255, 255, 255, 0.75)

Shadow style:
- Keep shadows soft and low opacity.
- Card shadow:
  0 12px 36px rgba(15, 23, 42, 0.06)
- Floating/premium shadow:
  0 24px 70px rgba(15, 118, 110, 0.10)
- Avoid harsh black shadows.


6. Login Page Direction
-----------------------
The login page should be full height with no vertical scroll.

Left side:
- Light mint/warm background
- Subtle grid
- Smooth connecting line art
- Large headline with 2-color gradient
- Small supporting text
- Circular floating metric cards
- Cards should move independently using GSAP
- Motion should be smooth, slow, and not distracting

Right side:
- Full-height login surface
- Form integrated into the right panel, not pasted like a separate card
- Centered content vertically
- Top icon can be used, but keep it tasteful
- Inputs should be large, clear, and soft
- Add password show/hide control
- Error state should be clear and accessible
- Submit button should be strong but not too dark

Right form rules:
- Avoid transform animation on the form panel.
- Fade in is okay.
- No vertical scroll.
- No unnecessary labels such as "Protected" unless needed.
- Keep text minimal.


7. Buttons
----------
Primary button:
- Height: 44px to 52px
- Radius: 8px
- Font weight: 500 or 600
- Background: emerald to teal to sky gradient
- Text: white
- Shadow: soft emerald shadow

Hover:
- Slight color shift only.
- Avoid strong scale or lift unless very subtle.

Disabled:
- Opacity 0.55
- No hover transform

Icon usage:
- Use lucide icons.
- Icon size: 16px to 18px in buttons.
- Keep icon spacing 8px.


8. Forms
--------
Input height:
- 44px for dense admin forms
- 48px to 52px for login and important forms

Input style:
- Border: soft emerald or slate border
- Background: white or very light mint
- Text: #1F2937
- Placeholder: #94A3B8
- Focus border: #2DD4BF
- Focus ring: rgba(45, 212, 191, 0.20)

Labels:
- 13px to 14px
- Weight 500
- Color #334155

Errors:
- Red border
- Light red background
- Clear text
- Use role="alert" where useful


9. Cards
--------
Dashboard cards:
- White or glassy white background
- 8px radius
- Soft border
- Subtle shadow
- Icon badge in top right or top left
- Title at 13px to 14px
- Value at 28px to 36px
- Body text at 13px

Metric circles:
- Use only for special visual areas such as login hero.
- Keep them round.
- Use slow floating animation.
- Avoid movement that hides text or overlaps important elements.

Card color system:
- Brands: emerald/teal
- Campaigns: sky/cyan
- Creators: amber/orange
- Admin or system: slate/indigo
- Error or risk: red/rose


10. Tables and Data Pages
-------------------------
Tables should feel professional and easy to scan.

Table headers:
- 12px to 13px
- Weight 600
- Uppercase optional
- Muted slate color

Rows:
- Height 52px to 64px
- Light bottom border
- Hover background: very light mint or slate

Cells:
- Main value: 14px, weight 500
- Secondary value: 12px to 13px, muted

Actions:
- Use icon buttons when possible
- Use clear primary action buttons for important workflows

Avoid:
- Heavy row shadows
- Too many pill badges
- Too many bright colors in one row


11. Sidebar and Navigation
--------------------------
Sidebar should be calmer than the current heavy black style.

Recommended sidebar:
- Background: deep teal/slate only if needed, but avoid pure black
- Alternative: light sidebar with active teal accent
- Active item: soft emerald background with teal text
- Icon size: 18px
- Text weight: 500

Navigation item height:
- 40px to 44px

Badges:
- Small
- Subtle border
- No heavy font-black


12. Dialogs and Modals
----------------------
Dialog style:
- White or warm white background
- 8px radius
- Soft border
- Soft shadow
- Header should not be overly dark

Dialog title:
- 20px to 24px
- Weight 600

Dialog body:
- 14px
- Muted text for helper copy

Buttons:
- Primary on right
- Secondary/cancel on left or before primary


13. Animation and Motion
------------------------
Use GSAP only where motion adds polish.

Motion rules:
- Smooth
- Slow
- Subtle
- No sudden jumping
- No animation on critical form usability

Good animation:
- Fade in
- Soft blur reveal
- Slow floating hero objects
- Gentle line drawing
- Small icon shimmer

Avoid:
- Fast bouncing
- Too much rotation
- Form panel transform animation
- Animations that create layout shift

Recommended durations:
- Fade reveal: 0.5s to 0.8s
- Hero word reveal: 0.7s to 0.9s
- Floating cards: 3.5s to 6s per move
- Background line scan: 3s to 5s

Respect reduced motion:
- Keep current prefers-reduced-motion guard.


14. Responsive Rules
--------------------
Desktop:
- Split layout can be used on login page.
- Left side visual, right side form.

Tablet:
- Simplify left visuals.
- Reduce heading size.
- Reduce card motion.

Mobile:
- Hide left hero.
- Show only login form.
- Full-height layout.
- No horizontal or vertical overflow.
- Inputs should remain at least 48px tall.


15. Accessibility
-----------------
Maintain:
- Clear labels for inputs
- aria-label on icon-only buttons
- role="alert" for login errors
- Visible focus ring
- Enough color contrast
- Do not rely only on color to show errors

Text contrast:
- Main text should be dark slate, not pale gray.
- Gradient text should remain readable.


16. Implementation Priorities
-----------------------------
Step 1:
- Finalize login page composition.
- Remove scroll.
- Keep right form full height and integrated.

Step 2:
- Normalize global typography.
- Reduce font-black usage across the app.
- Replace with font-medium and font-semibold.

Step 3:
- Update sidebar and topbar.
- Make navigation more professional and less heavy.

Step 4:
- Update dashboard stat cards.
- Use consistent card style and spacing.

Step 5:
- Update tables.
- Improve scanning, row spacing, and action buttons.

Step 6:
- Update dialogs and forms.
- Make all create/import dialogs consistent.

Step 7:
- Review colors page by page.
- Remove random gradients.
- Keep palette consistent.


17. Final Design Rules
----------------------
Use this checklist before approving any page:

- Does the page feel calm and premium?
- Is typography consistent?
- Are weights mostly 400, 500, and 600?
- Are colors from the approved palette?
- Is there enough white space?
- Are cards simple but polished?
- Does the UI avoid pure black?
- Are buttons consistent?
- Do forms feel usable and clear?
- Is there no unwanted scroll on login?
- Are animations smooth and subtle?
- Does the page look like a real SaaS product, not AI-generated?
